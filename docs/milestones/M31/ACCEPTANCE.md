# Milestone 31 — Formatter v1.0 Final Certification

## Purpose

M31 is the final certification gate for TheMITbro Formatter v1.0.0.

It certifies the M30 release-candidate baseline for production use without
changing the established renderer contracts.

## Certification gates

- Repository structure
- Python source integrity
- Complete regression suite
- Overall coverage >= 90%
- Critical production-module coverage
- Real-world representative corpus
- PDF/HTML/SVG production smoke validation
- Deterministic output
- Release cleanliness
- Release manifest and audit

## Release target

- Version: `1.0.0`
- Status: `stable`

M31 is complete only when the M31 workflow and the main regression workflow
are both green.
