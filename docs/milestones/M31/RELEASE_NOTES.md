# TheMITbro Formatter v1.0.0

This release certifies the formatter as the v1.0.0 production baseline.

### Included

- Stable rendering pipeline
- Mathematical normalization and validation
- Question-paper rendering

- SVG validation
- Regression corpus coverage
- Release cleanliness checks
- Deterministic-output certification
- Release manifest and final audit

The existing public/build/input contracts are preserved. M31 is a
certification milestone, not a breaking rewrite.
